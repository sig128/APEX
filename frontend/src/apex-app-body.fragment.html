PLAYER PROFILING VARIABLES — PRO ODDSMAKER DEPTHEVERY BATTER SCANNED
V.01
Hot/Cold Streak Detection
L7D / L15D / L30D slash lines. wRC+ rolling window. Is the streak xStat-supported or BABIP luck? Sustainable streaks = edge. Lucky streaks = fade OVER.
V.02
RISP Performance
BA/OBP/SLG with runners in scoring position — season + career + L30D. High RISP + projected high-scoring game = RBI prop OVER signal. Cross-ref with clutch index.
V.03
OBP / Walk Rate / Discipline
BB% + O-Swing% + Chase Rate. Disciplined hitters extend ABs and reach base more. Key for Hits O0.5, Runs Scored, and bases-reached props.
V.04
Platoon Splits (Granular)
Career + current season vs LHP and RHP separately. ISO splits, K% splits, BABIP splits. Some hitters have 100+ point OPS gaps by handedness.
V.05
Batted Ball Profile
GB% / FB% / LD% + Pull% / Center% / Oppo%. Barrel% and HardHit%. EV90 (top 10% exit velo). xSLG. Launch angle tendencies. Match to park factors.
V.06
Lineup Position & PA Volume
Today's lineup slot vs usual slot. PA/game expectation. Moving from 2nd to 6th = ~1 fewer PA = massive prop impact books may lag on.
V.07
Batter vs Pitcher History
H2H stats BUT filtered by sample size. <20 PA = noise, ignore. 40+ PA = meaningful. Check recency — recent H2H (last 2 seasons) matters more than career.
V.08
Pitch Type Vulnerability
How does batter perform vs the starter's primary pitch mix? If starter throws 60% slider and batter whiffs 40% vs sliders = K prop OVER signal.
V.09
Home/Away Splits
Some hitters have massive home/away splits. Park familiarity, comfort, travel fatigue, altitude adjustment all factor.
V.10
Day/Night + Day-of-Week
Day game after night game = fatigue. Some hitters historically hit differently day vs night. Thursday getaway games = lineup rest risk.
V.11
Speed & Stolen Base Profile
Sprint speed, SB attempts, success rate, catcher pop time, pitcher slide step. For SB props and runs scored probability.
V.12
Injury / Workload Flags
Recent IL stints, pitch count limits, nagging injuries, pinch-hit risk. If a hitter might get pulled in the 6th, UNDER props gain edge.
