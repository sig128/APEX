# Invite codes and plan codes live in Firestore, collection: inviteCodes (document ID = the code).
#
# Option A: seed from your machine (keep the service account JSON out of git):
#   cd functions
#   GOOGLE_APPLICATION_CREDENTIALS=/absolute/path/to-adminsdk.json npm run seed-invites
#   # plan codes: 10 codes, each gives 30 days of Elite, one use per code
#   INVITE_CODE_COUNT=10 INVITE_PLAN=elite INVITE_DAYS=30 GOOGLE_APPLICATION_CREDENTIALS=... npm run seed-invites
#   # one shareable code for 100 people, 7 days of Pro, expires in 14 days
#   INVITE_CODE_COUNT=1 INVITE_USES=100 INVITE_PLAN=pro INVITE_DAYS=7 INVITE_EXPIRES_DAYS=14 ... npm run seed-invites
#
# Option B: Firebase Console > Firestore > inviteCodes > Add document (ID = the code people type)
#   Make the ID long and random (16+ characters, like APEX-K7QM-2XWD-9RTH-B4NP). Short or
#   guessable codes can be found by trial and error, and plan codes grant paid passes.
#   active        boolean  true
#   usesRemaining number   1          (leave it out for unlimited)
#   plan          string   pro|elite  (leave it out for a plain invite)
#   days          number   30         (or the string "lifetime")
#   expiresAt     timestamp           (optional: the code stops working after this)
#
# People redeem codes on their Account page. A plain invite unlocks the AI while the paywall is
# off; a plan code adds that pass to their account (stacking on time they already have). Each
# person can use a given code once.
